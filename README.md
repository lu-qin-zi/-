# 英语单词默写小程序

用 Python 写的一个命令行背单词工具，词表是物联网/嵌入式专业词汇，
背单词和专业课一起推进。

## 用法

```bash
python 错题本.py
```

运行后会随机显示一个英文单词，输入中文意思：

- 答对 -> 提示"恭喜你答对了"，继续下一题
- 答错 -> 可以再猜，输入"不要"就看答案
- 输入 q -> 退出程序

## 词表格式

词表文件：`单词本-物联网30词.txt`

```
sensor,传感器
voltage,电压
clock,时钟
```

规则：
- 一行一个单词
- 英文和中文之间用**英文半角逗号**分隔
- 不要留空行（空行会被当成一条空单词）
- 多个中文释义用 `/` 分隔，例如 `water,水/自来水`

## 文件说明

| 文件 | 作用 |
| --- | --- |
| 错题本.py | 主程序：读词表、随机抽词、判分、重猜 |
| 单词本-物联网30词.txt | 词表，30 个物联网专业词 |
